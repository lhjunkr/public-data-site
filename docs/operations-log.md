## 11/28 — 출처별 매일 갱신 · 대량 비활성 상한 "마감 전만" 로컬 확인 (12/16)

맥 로컬에서 `bash scripts/check-schedule-local.sh`로 테스트를 돌린 뒤, 예약 시각만 명령줄 인자로 2 ~ 5분 뒤(`--batch.crons.출처=…`, 온통청년은 `-`)로 덮어써 앱을 켜고 4개 출처가 스스로 도는지 봤다. 결과 원문은 `build/check-schedule.txt`(리포 밖).

| 확인 | 결과 |
|---|---|
| 테스트 | **300개 통과** (285 → 300: 예약 7 · 매일 갱신 출처별 4 · 상한 "마감 전만" 4) |
| 예약 로그 | `매일 갱신 예약 — kstartup 0 43 18 * * * · myhome 0 44 18 * * * · alio 0 45 18 * * * · cleaneye 0 46 18 * * *` |
| K-Startup | 18:43:00 시작 → 18:43:02 완료 · 수집 177/177 · 적재 177 · 실패 0 · 비활성 22 · `collect_run` SUCCESS 1초 |
| 마이홈 | 18:44:00 → 18:44:04 · 수집 396/396행 · 적재 215 · 실패 0 · 비활성 27 · SUCCESS 3초 |
| 잡알리오 | 18:45:00 → 18:45:06 · 수집 577/577 · 적재 577 · 실패 0 · 비활성 0 · SUCCESS 5초 |
| 지방공공기관 | 18:46:00 → 18:46:20 · 수집 535/535행 · 적재 522 · 실패 0 · 비활성 0 · SUCCESS 19초 |
| 활성 (출처별) | 온통청년 3,994 · K-Startup 177 · 마이홈 215 · 잡알리오 577 · 지방공공기관 522 |
| 마감이 지났는데 활성 | 온통청년 **1,589** · 나머지 4개 출처 0 |

- 4개 모두 예약한 분의 0초에 시작했고, 앞 출처가 1분 안에 끝나 잠금 충돌(건너뜀)은 없었다.
- K-Startup 비활성 22 · 마이홈 27은 마지막 로컬 수집(11/26 · 11/27) 뒤 이틀 동안 마감 · 종료된 공고다. 상한 바닥(50) 아래라 규칙 변경과 상관없이 통과다.
- 온통청년은 마감일이 지난 정책 1,589건을 계속 응답에 담아 준다(매칭은 날짜로 거른다). 새 규칙에서는 이 1,589건이 한꺼번에 응답에서 빠져도 상한에 세지 않는다 — 마감이 지난 정책의 정리라 정상으로 본다. 나머지 2,405건(마감 전 · 상시) 중 상한(399건)을 넘게 빠지면 예전처럼 멈춘다.
- 공고형 4개 출처는 마감이 지난 활성이 0이다 — 진행 중 · 모집 중만 받으므로, 마감이 지나면 다음 수집에서 빠져 비활성된다. 이번 규칙이 겨냥한 경우다.
